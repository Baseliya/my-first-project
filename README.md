# 💰 AI-агент «Сімейний бюджет»

Telegram-бот на базі Claude, який веде сімейний бюджет:

- 📸 **Чек (фото або PDF)** → розписує кожен товар: назва, кількість, сума, категорія, магазин.
- ✍️ **Текст** → «350 продукти АТБ», «хліб 32, молоко 45», «вчора таксі 180» або просто «250».
- 📄 **Виписка з банку / таблиця витрат (CSV, XLSX)** → розкладає витрати за категоріями, знаходить надходження.
- ❓ **Питання** → «скільки ми витратили на каву цього місяця?»
- 📈 **10% на інвестиції** → від кожного внесеного доходу 10% резервується на інвестиції; бот рахує, скільки ще можна витратити і денний ліміт.
- ⏰ **Щодня о 21:00** — список покупок за день, суми за категоріями, стан бюджету та поради, де заощадити.
- 📊 **В останній день місяця** — великий розгорнутий аналіз: куди пішло найбільше, топ товарів і магазинів, порівняння з минулим місяцем, виконання плану інвестицій, план економії та ліміти на наступний місяць.

## Команди бота

| Команда | Що робить |
|---|---|
| `/today` | звіт за сьогодні з порадами |
| `/list` | список покупок за сьогодні |
| `/month` або `/month 2026-09` | розгорнутий аналіз місяця |
| `/income 45000 зарплата` | внести дохід (база для 10% інвестицій) |
| `/invested 4500` | відмітити, що відклали на інвестиції |
| `/undo` | скасувати останнє завантаження |

## Запуск

1. Створіть бота у Telegram через [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Отримайте ключ API на [console.anthropic.com](https://console.anthropic.com).
3. Скопіюйте `.env.example` у `.env` і заповніть `ANTHROPIC_API_KEY` та `TELEGRAM_BOT_TOKEN`.
4. Запустіть:

   ```bash
   python3 -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   python -m budget_agent
   ```

   або в Docker:

   ```bash
   docker build -t family-budget .
   docker run -d --restart unless-stopped --env-file .env -v $(pwd)/data:/app/data family-budget
   ```

5. Напишіть боту `/start` — він покаже ваш chat id. Додайте його (і id інших членів сім'ї через кому) в `ALLOWED_CHAT_IDS`, перезапустіть бота.

Бот має працювати постійно (домашній комп'ютер, VPS, Raspberry Pi), щоб надсилати звіти о 21:00.

## Налаштування (`.env`)

| Змінна | За замовчуванням | Опис |
|---|---|---|
| `TIMEZONE` | `Europe/Kyiv` | часовий пояс |
| `DAILY_REPORT_TIME` | `21:00` | час щоденного звіту |
| `CURRENCY` | `грн` | валюта |
| `INVEST_RATE` | `0.10` | частка доходу на інвестиції |
| `DB_PATH` | `data/budget.db` | файл бази SQLite |

## Як це влаштовано

- `budget_agent/ai.py` — виклики Claude (`claude-opus-5-5`): розбір чеків і виписок у структурований JSON, поради та місячний аналіз.
- `budget_agent/analytics.py` — усі суми, частки й ліміти рахуються кодом, а не AI, тому цифри у звітах точні.
- `budget_agent/db.py` — SQLite: покупки, доходи, інвестиції.
- `budget_agent/bot.py` — Telegram-бот і розклад звітів.

Порада: не завантажуйте і чеки, і банківську виписку за ті самі покупки — вони задвояться. Обирайте щось одне або скасуйте зайве через `/undo`.

Тести: `pip install pytest && python -m pytest`
